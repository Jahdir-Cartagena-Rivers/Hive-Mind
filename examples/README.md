# Synthetic examples

These files contain invented demonstration data for the fictitious Nebula
project. There are no actual conversations, account memories, credentials,
databases, or source-bank exports. They retain the MIT permissions of the earlier
showcase under ../licenses/LEGACY-MIT.txt.

The canonical record and its managed Markdown note have matching identities and
fingerprints. A correction from copper to aluminum illustrates revision checking:
a concurrent correction produces a conflict rather than silently overwriting
the current record. Create production memories through the API instead of
copying the illustrative JSON file into live state.

The example configuration uses demonstration paths and a dedicated bank. Adapt
the paths through the standalone API only in an isolated environment. The thermal
review example is a catalog description; discovery does not execute the skill.

Never replace these fixtures with actual user records or vault exports.
