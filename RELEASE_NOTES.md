# Hive Mind 0.7.0 ? source staging

Adds immutable original evidence, linked revisioned decisions, versioned AI
interpretations, explicit normalized/ChatGPT/Claude import support, opt-in text
folder capture, question-filtered timeline/table/evidence views and synthetic
retrieval evaluation. Queries can find decisions through their source evidence.
Inactive interpretations and rejected decisions stay out of working context;
forgetting evidence removes dependent derived claims.

Includes the general-memory null-project compatibility repair shipped in 0.6.2.
This staging version is not a deployed Rust rewrite. Shared-profile rollout needs
compatible readers on all relevant replicas before new record kinds are written.

Adds scoped Insights for explicit contradictions, recorded resolutions and
outcomes, older open tasks, and labeled suggestions from repeated user
corrections. Suggestions do not modify preferences.
